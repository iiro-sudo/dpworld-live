Tämä on osittainen pistevertailu, ei virallinen PGA-korttiranking. Vertailussa on vain ne pelaajat, joiden lähtöpisteet ovat laskennan käytettävissä. Korttipaikan varmistumista tai todellista korttisijaa ei voi päätellä tästä taulukosta.

Lähteet ja päivitykset

Kilpailutulokset: Sportradar Golf API. GitHub Actions hakee tulokset ja laskee osittaisen pistevertailun `snapshot.json`-tiedostoon. Netlify julkaisee GitHubiin tallennetut päivitykset.

Selain tarkistaa tiedoston automaattisesti kahden minuutin välein. Päivitys näkyy GitHub Actionsin ja Netlifyn julkaisun jälkeen.
